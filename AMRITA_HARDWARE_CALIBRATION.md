## ⚡ 2. ПОШАГОВЫЙ АЛГОРИТМ ЗАПУСКА И КАЛИБРОВКИ

### Шаг 1: Активация 108 Монет Сознания (Инициализация Ядра)
Запустите корневой оркестратор. Программа сгенерирует 108 уникальных криптографических хэш-патентов:
```bash
python3 amrita.py
```
*Критерий успеха:* В консоли должен появиться статус `AMRITA OS // MULTIVERSE TIME CHORD ACTIVE` и отобразиться залоченные узлы `LOCKED_IN_ATOM_CORE`.

### Шаг 2: Настройка Временного Смещения (`GalaxyTimeExplorer`)
Для того чтобы генератор мог брать информацию из Кибернета и материализовать ее в физическом пространстве, необходимо откалибровать длину волны времени. Сдвиньте интент электрона в режим материализации:
*   Установите режим волны на работу с отрицательной силой **E = -c¹⁷**.
*   *Проверка:* Длина волны времени в консоли должна принять стабильное значение, рассчитанное через шаг модификатора Золотого Сечения `LAW_PHI = 1.6180339887`.

### Шаг 3: Калибровка Волновой Хроматики (Wave Chromatics)
В модуле `AmritaGalaxySpaceExplorer.py` вызовите скрытые частоты спектра:
1.  Для утилизации избыточной массы старого мира в свет активируйте частоту **`PINK_MAGENTA` (380.0 PHz)**.
2.  Для кристаллизации голограмм в твердые атомарные структуры (Лего из Света) активируйте частоту **`TURQUOISE_MAGIC` (500.0 PHz)**.
*Примечание:* Использование этих частот полностью обходит блокировки старой банковской системы и выводит КПД прибора на уровень 40% по Золотому Сечению.

### Шаг 4: Запуск Квантового Материализатора


*Критерий успеха:* На выходе в терминале должны отобразиться точные аппаратные подписи блоков (например, `GEN-HARD-...`), подтверждающие успешный виртуальный вывод структуры жилья (`HOUSING_MATRIX`) и органического питания (`BIOLOGICAL_FOOD`) из Разумной Светимости.
