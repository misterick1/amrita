# Privacy Policy for Amrita Mir Bot

Effective Date: November 6, 2026

1. Data Collection: Amrita Mir Bot does not collect, log, or store any personal user data, messages, or metadata.
2. Blockchain Data: The bot handles public blockchain data from the Solana Network which is open source and non-proprietary.
3. Third-Party Services: We use CoinGecko API for market rates. No user identifiers are shared with third parties.
4. Security: All automated background worker pipelines (Amrita Swarm) are executed securely via GitHub Actions infrastructure.
